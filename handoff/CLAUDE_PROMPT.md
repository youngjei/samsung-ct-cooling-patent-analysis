너의 작업은 미국 DLC/액침 특허의 실제 데이터를 수집·정제하고, 연도별 추이·성장률·CPC 변화·출원인 집중도(HHI)·신규 출원인·건물/설비 연계·핵심특허와 협력 후보를 분석하는 것이야. 계획된 범위는 미국 출원 2000–2024년이고, 검색 서비스·단위·필터를 명시해. S커브는 충분한 데이터와 식별 가능한 모형일 때만 수행하고 불안정하면 그렇게 보고해줘.

가장 먼저 팀원2에게 넘길 DLC/액침별 핵심특허 목록을 만들어줘. 목표는 각 최대 10건이지만 부족하면 억지로 채우지 말고, 실제 공개/등록번호·패밀리·선정 이유·지표·원문 및 청구항 URL을 포함해. 상세 필드는 TEAM1_HANDOFF.md에 있어. 이 목록이 있어야 팀원2가 미국 청구항 비교를 완성할 수 있으니 모든 그래프 완성까지 미루지 마.

반드시 원본 export, 실제 검색식, 검색일, 정제·제외·출원인 정규화·중복 처리 기록, 계산 코드와 표를 남겨줘. 필요한 사이트 접근이나 데이터 export가 불가능하면 그 제한을 알리고 필요한 입력을 구체적으로 요청해. 가상 데이터나 검색 결과 수만으로 특허 건수·피인용·HHI·성장률을 만들어내지 마.

국내 44건은 미국 산업 전체 데이터가 아니고, 국내 청구항 4건은 미국 Top 10이 아니야. 삼성 계열사의 특허를 삼성물산 소유로 합산하지 마. 과거 144→114와 초안의 AHP 5:1·HHI 0.18은 검증된 결과로 재사용하지 마. 특허점유율은 시장점유율과 구별하고, 미확인은 기술 부재로 단정하지 마.

최종적으로 team1/ 아래에 원자료·정제 데이터·분석 코드·그래프·핵심특허 반환표·결과팀용 요약·슬라이드별 대본을 정리해줘. 팀원2 파일은 보존하고 오류가 있으면 근거와 수정 제안을 남겨줘. 표의 칸을 채우는 것보다 실제 근거와 분석의 일관성이 중요해. 우선 읽은 자료, 기존 작업과의 차이, 확보해야 할 데이터와 첫 실행 단계를 짧게 정리한 뒤 실제 작업을 진행해줘.
