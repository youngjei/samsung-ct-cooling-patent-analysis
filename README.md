# Samsung C&T Cooling Patent Analysis

삼성물산 AI 데이터센터 냉각 신사업을 검토하는 기술경영 팀프로젝트의 **특허 분석·전략 인계 자료**입니다. 2026-11-08 기준 팀원2의 국내 검색·청구항·협력관계 분석과 2026-11-09 기준 팀원1의 미국 정량분석을 정리했습니다. 삼성물산의 공식 자료나 완성된 산업 전체 특허조사가 아닙니다.

## 해석할 때 지켜야 할 구분

- 삼성물산·데이터빈 공동등록 2건은 전체 삼성물산 냉각 특허 총수가 아닙니다. 계열사 특허도 삼성물산 소유로 합산하지 않습니다.
- 국내 44건 선별 결과로 미국 기술 성장률·시장점유율·HHI를 계산하지 않습니다. 특허 점유율은 시장점유율이 아닙니다.
- 보완 Q6/Q7/Q8은 기존 후보와 중복됩니다. 결과 수를 단순 합산하지 않습니다. Q8 82건은 제목 및 근접 후보 초록을 확인한 탐색 결과이지 전체 청구항 검토가 완료된 집합이 아닙니다.
- 과거 중간발표의 144→114는 기간·검색식·검증 상태가 달라 이번 최종 분석에 재사용하지 않습니다.
- 국내 4건은 목적표집 사례입니다. 미국 Top 10을 대신하지 않습니다. 검색에서 미확인은 기술 부재를 의미하지 않습니다.
- AHP 5:1, HHI 0.18 같은 기존 초안 값은 검증된 결과가 아닙니다. 실제 데이터·판단 근거 없이 점수를 채우지 않습니다.

## 재현

이미 생성된 Excel·PNG·HTML은 별도 환경 없이 열어볼 수 있습니다.

```bash
node validate_supplement.mjs
```

위 검증 스크립트는 Node.js 기본 모듈만 사용하며, 기존 44개 출원번호와 분류 검색 4건의 중복을 검증하고 보완 기록을 생성합니다.

팀원1 미국 분석은 Python으로 재현합니다.

```bash
cd outputs/team1_20261109/analysis
pip install -r ../requirements.txt
python clean.py && python build_core_list.py && python run_analysis.py && python specialists.py && python facility.py && python validate.py
```

`validate.py`는 원본 해시, 국가·출원일 필터, 검색식 준수, 원본→정제 대조, 연도별 합계, HHI 재계산, 반환표 필수 필드를 점검해 `validation.json`에 남깁니다. 미국 데이터는 Lens 출원일(Filed) 필터 기준이며, Lens 기본값(Published)으로 받으면 최근 출원이 빠집니다.

그림 재생성은 Playwright와 Chromium이 필요합니다. `npm install` 및 `npx playwright install chromium` 후 `npm run figures`를 실행하세요. macOS에서 만든 기존 이미지와 다른 OS에서는 한글 글꼴에 따라 줄바꿈이 달라질 수 있습니다. 생성 후 직접 확인해야 합니다. 설치된 Chrome을 사용할 경우 `CHROME_PATH`로 실행파일을 지정할 수 있습니다.

`build_workbook.mjs`는 원래 작성 환경의 `@oai/artifact-tool`을 사용하는 보존용 생성 코드입니다. 일반 Node 설치만으로 재생성을 보장하지 않습니다. 결과 Excel, 원자료 TSV, 검색식은 함께 제공되므로 다른 도구로 계산·검토할 수 있습니다.
