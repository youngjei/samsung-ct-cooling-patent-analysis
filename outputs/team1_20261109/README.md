## 정제 (`analysis/clean.py` → `clean/`)

1. **등록특허:** grant 파일에서 Document Type = Granted Patent만 남김.
2. **비대상 제외:** 무작위 50건 점검 결과를 보고 키워드로 후보를 찾아 하나씩 읽어 명백한 비대상만 제외(DLC 3, 액침 16 패밀리. 디자인 특허 2건 포함). `clean/excluded_records.csv`.
3. **출원인 정규화:** 원 명칭은 그대로 두고 `applicant_normalized` 열 추가. 회사명이 있으면 개인(구 미국 출원의 발명자 표기)은 빼고, 개인만 있으면 최초 권리자(`Owners`)를 씀. 계열 법인·개명 통합표는 `clean.py`의 `SAME_NAME`.
4. **중복:** 패밀리 단위(simple family 1건 = 1). 핵심특허는 같은 simple family에서 1건만.
5. **분류 경계:** 칩 분사·제트 냉각, 냉매·상변화(2상) 표현이 있는 패밀리는 `boundary_tag` 열로 표시(제외 안 함).
6. **두 기술 중복:** 두 검색에 모두 걸린 23 패밀리는 양쪽에 포함하고 `both_tech` 열로 표시.

결과: DLC 451 패밀리(등록 354), 액침 163 패밀리(등록 157). `clean/cleaning_log.csv`.

## 분석 단위와 정의

`analysis/특허분석_결과.xlsx`의 `정의` 시트에 정리했다. 요점:

- **연도:** 패밀리의 최우선일(처음 출원한 해). 강의의 우선권 설명을 따름. S커브도 등록특허의 최우선연도.
- **성장률:** 5년 합계 비교(2013–2017 vs 2018–2022). 2023–2024는 공개 지연으로 뺌.
- **HHI:** 0–1 척도. 완전계수(공동출원인 각 1건) 기본, 분할계수 병기, ×10,000 값도 표기.
- **건물 연계:** CPC E04B·E04F·E04H(건물) 또는 F24F(공조)가 함께 붙은 패밀리 비중. E04G(비계·거푸집)는 뺌. 분류 기반 대리지표.
- **CPC 구성비:** 패밀리 중 해당 그룹 코드를 하나라도 가진 비율(그룹 간 중복 가능).
- **S커브:** 등록 누적, Logistic·Gompertz, 2000–2021. 2021년이 각 모형의 변곡점(Logistic L/2, Gompertz L/e) 앞인지 뒤인지로 판정. 포화수준 L은 식별되지 않아 '누적/L 몇 %'는 결론에 쓰지 않음. 종료연도 2019·2020은 민감도로 보관. 검증 구간: 2000–2018로 적합해 2019–2021 예측(2021 누적을 DLC 28~33%, 액침 55~58% 적게 예측 → 모형 단독 판정은 불안정).
- **HHI 계산표:** `*_HHI계산` 시트에 전 출원인의 비중·비중²·분모·비중 합.
- **분류 경계:** `boundary_tag` 열. 분사·제트 냉각(DLC 3, 액침 1), 냉매·상변화 표현(DLC 43). 제외하지 않고 표시만 함.
- **강의 보조 지표:** 발명자 수, 비특허문헌 인용(1건 이상 비율), 패밀리 출원국.

## 한계

- 검색식이 서버·데이터센터 표현을 요구해 부품 수준 냉각판 특허(냉각 전문기업)가 덜 잡힌다. 냉각 전문기업 수치는 하한값이다. 시설 쪽 누락은 검색식 C로 따로 점검했다.
- 2022년 이후 우선일 출원은 공개 지연으로 덜 관찰된다.
- 피인용은 영향력의 대리지표다. 법적 상태는 Lens 표기이며 침해·FTO 판단이 아니다. 특허 점유율은 시장점유율이 아니다.
- 강의 지표 중 인용한 선행문헌의 연도(기술변화 속도), 인용 관계망, 청구항 수는 Lens CSV에 필드가 없어 하지 못했다. 핵심특허 20건의 청구항은 팀원2가 원문에서 확인한다.
